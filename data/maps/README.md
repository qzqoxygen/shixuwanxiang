# 中国省级基础地图

阶段一用于本地学习交流预览；不是文化案例数据，不代表文化案例覆盖范围。

- 文件：`china-provinces.geo.json`，保留下载的 GeoJSON 原始内容。
- 来源：[阿里云 DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/atlas_aigc)。来源页面说明数据来自高德开放平台、areas_v3 版本更新于 2021.5、仅供学习交流使用；不把它描述为最新行政区划。
- 下载地址：<https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json>
- 获取日期：2026-10-29。
- SHA-256：`99adfeded5223848bbe37a0a12f8023e11ee12161c7800521c27db42fdeac275`。
- 组成：34 个具名省级行政区，以及 `100000_JD` 海上界线辅助要素。辅助要素不是省份，不计入省份数量或未来案例编码白名单。
- 编码：数据的数字 adcode 在组件输出时转为六位字符串，与 V1.0 协议一致。

`node scripts/build-map-geometry.mjs` 将原始坐标投影为 `public/images/china-province-geometry.svg` 和 `data/maps/province-labels.json`，可加 `--check` 验证生成文件。主图与南海诸岛附图使用同一份数据、各自的 Mercator 投影和裁切窗口，保留海岛及海上界线。拥挤地区的名称使用引线调整标注位置。浏览器从本站加载一份 SVG，地图各层共用其中的边界。

2026-10-30 已增加省份悬浮预览、点击选定、键盘回车/空格选定、Escape 取消及 34 省级行政区下拉列表。交互命中区域固定，省域画面与地名向上移动，浮起画面置于其他省域上方，地名单独置顶；小行政区增加地名感应区域。手机使用点击与列表；减少动态效果偏好下取消位移动画。选定状态只在内存中，刷新清空，未接入文化案例、地理检索或 AI 地图控制。

地图底衬保持浅宣纸；省域内部不展示纸雕山水。浮起时呈淡青绿，选中描边为哑金色；整页左下角为小范围青绿线描山水装饰。素材说明见 [ARTWORK.md](../../public/images/ARTWORK.md)。未修改原始地理坐标。公开发布或比赛材料使用前，需另行确认底图的适用授权与地图使用要求；此数据来源不等于已取得公开发布许可。
