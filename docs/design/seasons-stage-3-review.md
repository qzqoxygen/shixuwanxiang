# 四时翻页：阶段 3 验收记录

日期：2026-11-06。状态：自动翻页生命周期已完成，用户已确认继续阶段 4。本文件保留阶段 3 的实现与验证记录。

## 当前体验

打开 http://127.0.0.1:3000/seasons 。点击下方前后按钮或使用左右方向键，纸页会绕中缝自动翻转，落页后恢复左文右图。

- 单次翻页时长配置为 820ms，使用阶段 2 验证过的正反面与旋转轴。
- 翻动中保留当前纸张的起点、终点、方向与序号，动画结束后才提交当前节气并清理纸张副本。
- 暂停动效时立即落到最新目标，后续切换改为直接更新内容；重新开启后可继续自动翻页。
- Home、End 在书本区域获得焦点时直接跳到卷首、卷末，不播放跨全册的逐页动画。
- 本阶段没有开启滑动翻页、目录跳转或页角特效。小屏仍可横向查看完整对页。

## 实现与恢复机制

1. 将已有导航状态拆到 `lib/book-navigation.ts`，复用“当前纸页固定，只保留最新待处理目标”的逻辑；对完成和异常恢复都检查动画序号。
2. 新增 `lib/book-turn-animation.ts`，统一处理完成、取消、接口不可用、启动异常、卸载及超时。超时保护配置为单次时长加 300ms，避免长期锁在翻页中。
3. 正常完成时保留纸张最后姿态，直到 React 提交目标底页并卸载纸张，避免先归零再消失的闪烁。卸载取消不再提交旧状态。
4. 页面隐藏、暂停或书页尺寸变化时归位到最新目标。使用 ResizeObserver 与窗口 resize 监听处理布局变化，并在卸载时清理监听。
5. 为主书本增加有垂直留白的横向滚动容器；书封允许纸张伸出，避免翻起时上下边缘被裁切。
6. 动画期间底页暂时 inert、隐藏于读屏；纸张副本一直不参与点击或读屏。完成后恢复底页交互。若从正文链接按方向键翻页，焦点先移回书本区域，保证后续键盘操作继续可用。
7. 移除未启用的旧手势代码及未配套样式的页角按钮，留待后续阶段独立接入。

### 实际浏览器

使用独立 Edge 标签页检查实际页面：

- 正向、反向翻动中均只有一张活动纸页；尺寸与两侧底页一致，纸页未被裁切。
- 正常落页后 `turning=false`、活动纸页数量为 0，底页 inert 及隐藏状态均解除。
- 翻动中暂停后直接落至雨水，暂停状态下再切换至惊蛰也正常；恢复动效后可继续自动翻页。
- 翻动中前往预览页，再返回四时页，最终落至春分并恢复可操作状态。
- 翻动中从桌面缩至 768px，完成归位后可继续向下一节气翻阅。
- 连续按 6 次向右键，最终显示第 7 个节气立夏，没有无限队列或遗留纸张。
- 在正文链接上按方向键，完成翻页后焦点位于书本区域。
- 375px 窄屏仍可前后翻页，没有页面级横向溢出；手机专用阅读与手势仍留到阶段 5。
- 最终页面保持左右等宽、顶部对齐，控制台 error/warn 为空。

验证边界：自动化新建标签页没有使原页面真正进入 `document.hidden=true`，因此不将该尝试计为后台隐藏验收通过。系统减少动态效果的响应逻辑已保留，本轮没有改动用户系统设置。实际切后台和系统偏好变化可在本轮人工验收中补查。
