# 随鼠标放大镜与按钮细化

基于合并 PR #10 后的最新 `main`（`3590182`），使用独立分支 `frontend/cursor-and-buttons`。

## 改动

- 桌面窗景恢复随鼠标移动的原生光标。两份 40×40 SVG 使用绿色镜圈、棕色手柄、暖金接环和浅色外沿；点击热点位于镜片中心。走近前显示加号，走近后显示减号，无需 JavaScript 逐帧跟随。
- 桌面鼠标模式隐藏固定放大镜入口，键盘聚焦时显示提示；触屏仍使用原有 44px 点击入口。系统强制颜色模式回退到原生缩放光标。
- 首页三个模块入口使用宣纸底色、柔和圆角、细边框与轻阴影；保留各模块原有强调色及跳转地址。
- 优化助手推荐问题、发送、清空、案例操作和窗口工具按钮的边框、背景、圆角及按下状态。禁用与键盘焦点仍清楚可辨。
- 仅修改 CSS 和公开 SVG 资源，没有修改问答、地图或造物业务逻辑。
