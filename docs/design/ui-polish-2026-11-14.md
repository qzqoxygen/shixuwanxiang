# 首页与问四时界面调整

基准：`origin/main` 的 `b6d44f8`，包含 PR #9 的案例查询、地图定位和造物联动。开发分支：`frontend/ui-polish`。

## 改动

- 首页窗景使用青绿镜圈、暖金手柄和宣纸底色的放大镜。走近时显示减号，退回时显示加号，按钮状态通过 `aria-pressed` 表达。窄屏使用 44px 图标按钮，保留整个窗景的点击与 Escape 返回。
- AI 助手使用不透明底色，避免地图与文字透入。调整消息、输入框、推荐问题和案例卡片的间距；对话区域独立滚动，输入区固定保留。
- 案例的地图、原文、制卡操作统一为文字按钮；窄面板采用两列，地图操作独占一行。来源仍为有下划线的可换行链接。
- 移除首页、四时、知时、造物、关于页面的链接箭头，以及案例卡片 SVG 箭头。展开提示改为“展开／收起”，窗口复位改为文字。四时保留“上一节气／下一节气”和目标节气名称。
- 本次未修改 AI 请求、工具调用、案例查询、地图定位、造物导入或服务端接口。

## 验证

- 现有自动测试：115 项通过。

- Edge 浏览器实际检查：首页放大镜在走近／退回状态间切换；首页“去知时看故事”跳至带节气与省份参数的知时页面。
- 手机视口 375×681：首页图标与季节选择互不重叠，知时导航和助手面板完整显示；推荐问题可填入输入框；本地无密钥时显示错误提示。
- 手机视口实际点击四时“下一节气”从立春到雨水，再返回立春；桌面对页布局截图检查完成。
