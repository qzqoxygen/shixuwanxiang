# 四时页左右翻书：分步恢复与实现计划

日期：2026-11-06。目标：保留宣纸青绿、左页节气介绍、右页高清照片的视觉，让用户可以向前、向后翻阅二十四节气。

进度（2026-11-07 更新）：阶段 0—5 已实现并经用户要求推进；阶段 6 纸张质感与动态投影已实现，自动检查及最终浏览器回归通过，等待用户验收。已补齐跨尺寸、横竖屏视口、动画中跨断点、完整往返及慢图/失败图检查，详见 [最终回归记录及覆盖边界](seasons-final-regression-2026-11-07.md)。真实手机及系统专项仍需单独验证。

## 依据与检查边界

本计划基于当前工作区的 `components/SolarTermsExplorer.tsx`、`app/seasons/seasons.css`、页面入口、既有设计说明，以及 `D:/projects/outputs/season-hd/card-desktop.png` 的旧版双卡截图。当前聊天没有可读取的打开页面，浏览器清单也没有现有页面，所以没有复现运行时“卡死”。以下区分已确认的代码断点和后续需要验证的风险。

本次只新增计划文件，不修改页面实现，不覆盖已有未提交改动。UI 技能的 Python 搜索入口在本机不可用，本计划采用已读取的交互原则及项目代码证据，不声称命中技能数据库。

## 已确认的断点

1. 组件已经输出 `seasons-book-stage`、`seasons-book-base`、`seasons-book-leaf`、正反面等节点，并调用 Web Animations API 执行 `rotateY`；项目 CSS 中没有对应的书页布局、透视、旋转轴、背面隐藏或叠放规则。逻辑和样式迁移未完成，是首要修复点。
2. CSS 仍保留 `.seasons-detail` 的 1.45∶1 双卡布局，但当前 JSX 不再使用该容器。旧版手机上下双卡规则不能直接解决新书页布局。
3. 节气标题已变成 `h3.seasons-term-title`，CSS 仍选择 `.seasons-term-heading h2`，标题样式失配。
4. 正文卡、照片卡仍自带淡入及位移动画。它们会随书页正反面的挂载重复执行，需要在翻书区域移除，避免与整体旋转叠加。
5. 现有 reducer 已包含当前页、目标页、翻页方向和序号保护；已处理连续输入、暂停、减少动态效果和页面隐藏。可以复用并独立验证，不必重新引入一套状态系统。
6. 当前 JSX 没有渲染旧版四季及 24 节气目录。旧截图及既有脚本的目录选择器、标题层级、按钮名称已不能直接作为新实现的验收依据。

以上能确认实现处于不完整状态，不能据此认定浏览器冻结或无限渲染的具体根因。后续运行时需单独区分布局错乱、动画未收尾、图片解码停顿和主线程阻塞。

## 先确定交互与几何

- 一个节气是一组对页：左文右图，共 24 组。界面进度主要显示“第几个节气 / 24”；纸页编号 01—48 为辅助信息。
- 桌面采用等宽对页，统一页高，中缝固定。沿用旧版的配色、字体、图文内容和 4∶3 照片画框，重新分配页内留白。
- 向后翻：右侧旧照片页绕中缝向左翻，背面为新节气文字页；底层右侧提前铺好新照片页。向前翻执行相反过程。
- 初版首尾停止，按钮明确禁用；目录允许跨节气直达，最多播放一次过渡，不播放漫长的逐页队列。
- 等宽是本方案实现平面书页旋转的前提。若坚持 1.45∶1 卡片宽度，需另选整体横向切换方案，不能直接把不同宽度的卡片当作同一张纸的正反面。
- 先完成桌面按钮翻页。手机作为独立阶段，采用单页阅读、横向过渡，保留左翻右翻操作，避免将桌面对页缩到无法阅读。

## 阶段 0：保留现场并建立可运行基线

**工作**：保存当前差异与相关文件快照；启动项目，记录桌面现状、控制台错误、首次翻页及连续翻页表现。通过关闭动画、使用纯色占位页、暂时跳过手势逐项定位故障层。

**验收**：能够指出故障发生在哪一层；有可恢复的原始状态及截图。此时不更换依赖、不扩大到其他页面。

## 阶段 1：完成静态书本

**工作**：补齐书本容器、等宽底层对页、中缝、统一页高、工具栏及前后按钮样式；修正标题选择器；移除书内旧卡片入场动画。先只渲染当前组，按钮直接切换内容，不播放旋转。

**验收**：桌面只出现一组左文右图；文字、照片、署名无裁切；切换节气不使中缝或按钮跳动；24 组内容全部可到达。

**交付**：可读、可切换的静态书本，作为后续所有动画的稳定底座。

## 阶段 2：用三个节气验证书页几何

**工作**：仅用立春、雨水、惊蛰制作隔离的翻页样例；底层为左右静态页，上层只有一张可翻动的纸。明确 `perspective`、`transform-origin`、`preserve-3d`、`backface-visibility` 和层级关系。先使用纯色编号占位页，再放入真实文字与照片。

**检查方法**：手动停在 0°、45°、90°、135°、180°，逐角度查看正反面及底层露出的内容。两个方向都检查；确保纸张与底页背景不透明。

**验收**：中缝不移动；无镜像字、穿透、重复照片或落位错边；正反面与底页尺寸一致。此阶段不接入拖拽或连续翻页。

## 阶段 3：接入一次完整的翻页生命周期

**工作**：复用现有 reducer 和 Web Animations API，将静态角度样例接入“准备 → 翻动 → 提交 → 清理”。可以先以约 600—800ms 调试，再根据实际阅读节奏调整。

- 触发时冻结本次 `from/to/direction/serial`，直到这次翻页结束。
- 提前准备正确底页和翻页正反面，动画结束后提交当前节气并卸载翻动层。
- 持续保留序号校验，旧动画回调不能提交新一轮状态。
- 对完成、取消、组件卸载、页面隐藏、暂停及减少动态效果分别定义收尾。
- 增加有限时长的恢复保护，并沿用序号检查；超时后落到明确的目标静态页。不能仅靠超时掩盖状态错误。

**验收**：按钮向前向后都正确；动画后 `turn` 清空、遮挡层移除、正文链接恢复可操作；离开再返回页面可继续使用。

## 阶段 4：接回 24 节气、目录和快速操作

**工作**：恢复可直达的节气目录，所有入口共用同一个导航函数；同步标题、照片、说明、来源和进度。明确快速输入采用现有的“完成当前翻页，再去最新目标”规则，最多保留一个待处理目标，不累积无限队列。

**图片策略**：保留当前及相邻组预加载，避免一次解码全部高清图；不要让图片失败无限阻塞导航。慢图有固定大小的占位，失败有来源入口，换页后可重新加载对应图片。

**验收**：连续快速点击、翻动中反向、跨季跳转、首尾边界均可收敛；最终显示最后一次目标，页码与实际内容一致；无永久“正在翻页”。

## 阶段 5：手势与手机布局

**工作**：先实现“横向滑动后触发完整翻页”，纵向仍可滚动；照片点击看大图与滑动翻页互不误触；小于阈值或取消手势不翻页。若需要拖到一半时纸张跟手，再作为独立增强，增加拖动进度和回弹状态。

手机默认单页阅读：一个节气内按阅读顺序呈现介绍与照片，横向切换整个节气；按钮和目录均可替代手势。桌面双页与手机单页共用节气索引，切换断点时先结束当前动画并保留目标节气。

**验收**：375px、768px、1440px 下可读且无横向溢出；纵向滚动不误翻；照片链接可点击；手势取消、旋转屏幕、切换断点后仍能继续翻页。

## 阶段 6：纸张质感与最终回归

**工作**：最后加入中缝渐暗、页边厚度、动态投影及轻微页角提示。动画主要改变 `transform`、`opacity`，避免每帧更改布局尺寸。装饰不改变书页尺寸、层级或状态流程。

**交付前检查**：

- 全部 24 组在静止状态下内容及来源一一对应。
- 正向、反向各连续翻阅至少一轮；首尾不越界。
- 快速点击、翻动中反向、目录跳转均回到可继续操作的静态状态。
- 动画期间切换标签页、暂停、启用减少动态效果、调整窗口尺寸均能正确收尾。
- 慢图、图片失败不导致空白布局或导航锁死。
- 键盘、可见焦点、状态播报正常；动画副本不进入读屏或键盘焦点序列。
- 为状态转换和过期回调添加有意义的测试；更新旧版浏览器验收脚本，覆盖正反向翻页及快速输入。
- 页面实现完成后执行项目要求的 TypeScript、ESLint、既有测试和生产构建；浏览器检查另行验证视觉与交互。

## 推进原则

每个阶段独立保存，附截图或短录像及验收结果。阶段 1、2、3 是优先里程碑：先稳定显示，再验证正反面几何，最后验证一次翻页闭环。前三阶段未通过，不加入跟手拖拽、复杂纸张弯曲或额外动画库。
