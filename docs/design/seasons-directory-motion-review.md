# 四时目录：平滑过渡与预览移除

日期：2026-11-06。阶段 4 验收调整已由用户确认继续阶段 5；本文件保留阶段 4 的实现及验证记录。

## 调整结果

- 移除“翻页预览”入口、对应路由、预览组件和专用样式。旧路由 `/seasons/flip-preview` 已不存在，原有阶段截图及本轮调整前文件备份保留在项目外输出目录。
- 用一个共享书签式选中框替代逐项突然切换的边框。书签沿 transform 移动，采用与书页相同的 820ms 时长和缓动；跨季时背景、边线和文字柔和过渡。
- 书签跟随正在翻动的纸页目标。翻动中再次选择其他节气时，用虚线提示最新待翻目标，完成当前纸页后再平滑前往该目标；不生成多个主选中框。
- 当前阅读项的 `aria-pressed` 仍在实际落页时提交。目录标题在“正在读”和“待翻至”间切换，保持单行占位，避免翻页时目录上下跳动。
- 初次加载直接定位书签；目录重排时重新测量并归位。暂停或系统减少动效时立即切换；装饰动画不可用时保持导航可用，卸载时清理动画及观察器。
- 保留左侧目录、完整桌面首屏、左文右图及原有翻页逻辑，没有新增依赖。

## 验证

- 浏览器观察到跨季动画的多个中间位置，例如从雨水到立夏时，选中框相对目录的位置由约 `(72, 41)` 经过 `(17, 154)`，最终落到 `(6, 177)`，确认不是瞬间切换。
- 暂停动效后遍历全部 24 个节气，书签均与按钮准确对齐，当前项与实际节气一致，主书签始终只有一个。
- 快速键盘混合输入时，正在翻往雨水，最新目标为清明，清明显示待翻标记；最终落到清明，书签准确对齐且待翻标记清空。
- 暂停模式下目录立即切换、无活动纸页；跨季落页和前后导航正常。
- 检查 1366×768、1280×720、768×1024、375×812 布局，无整体横向溢出。目录重排后书签准确落位；1366×768 视口顶部时翻页操作底边为约 756.8px，完整书本及操作仍在首屏。临时视口已恢复。
- 主页面不再包含预览入口；实际访问旧预览地址返回 404，生产构建的路由表也不再列出预览页。
- 55 项测试、TypeScript、ESLint、生产构建及差异空白检查通过。删除路由后首次类型检查读到了旧的生成类型，正常重新构建后已更新并通过；没有保留对旧路由的源码引用。本轮无新的 Next.js 反馈事项。

本轮实测了页面内暂停动效；没有更改操作系统的减少动态效果设置，不声称实测系统偏好切换。窄屏仍采用书本内部横向查看，手机单页及手势继续留待阶段 5。
