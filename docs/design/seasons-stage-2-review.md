# 四时翻页：阶段 2 验收记录

日期：2026-11-06。状态：三节气书页几何样例已由用户确认。后续进度见 [阶段 3 验收记录](seasons-stage-3-review.md)，以下保留阶段 2 的交付快照。

## 打开预览

访问 http://127.0.0.1:3000/seasons/flip-preview 。四时主页的书本工具栏也增加了“翻页预览”入口。

预览提供：

- 立春 → 雨水、雨水 → 惊蛰、惊蛰 → 雨水、雨水 → 立春四组顺序，覆盖两个方向。
- 真实图文、编号色块两种内容，便于识别每个页面及其正反面。
- 0°、45°、90°、135°、180°固定姿态按钮，以及可用鼠标或键盘调节的连续角度滑块。
- 目标节气、起始与落页状态说明；预览中的图文链接不进入焦点序列，也不处理点击。

阶段 2 只控制姿态，不启动定时动画或连续翻页。四时主页继续使用阶段 1 的静态内容切换。

## 本阶段实现

1. 从 `SolarTermsExplorer.tsx` 提取 `components/seasons/BookPages.tsx`，主页与预览共用相同的文字和照片页面，避免样例与实际页面尺寸不一致。
2. 新增 `components/seasons/BookTurnPreview.tsx`、预览路由及其样式，独立保存样例状态。
3. 在 `book.css` 中补齐 6000px 透视、半宽书页、按方向设置的中缝旋转轴、正反面定位、背面隐藏及 3D 保持。
4. 正向：底层为旧文字页和目标照片页，活动纸张正面为旧照片页、背面为目标文字页。反向执行相反组合。
5. 正反面都使用不透明纸面；活动页在底页及中缝之上，页面尺寸与底页一致。
6. 修复翻起纸页被书封裁切的问题：预览书封允许纸页溢出，并在外围预留垂直空间。窄屏的横向滚动由外层书本容器承担，不裁切纸页上下边缘。
7. 为当前渲染的照片明确使用 `loading="eager"`，消除首屏图片懒加载提示。每次只渲染本次样例所需的照片，没有同时加载全部 24 张。

## 验收建议

先选“立春 → 雨水”，按 0°、45°、90°、135°、180°顺序查看。再选“惊蛰 → 雨水”反向查看；可切换编号色块确认纸页编号。重点观察中缝是否固定、字是否正向、纸页是否被裁切、落页后是否恢复左文右图。

本阶段确认后，阶段 3 再把这些姿态接入一次完整的自动翻页生命周期，处理完成、取消及异常收尾。
